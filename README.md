# econ3916-lab01-data-portfolio
ECON 3916 Lab 01 — Data Portfolio
The Data Portfolio — Big Mac Index Analysis
Objective

Analyze The Economist’s Big Mac Index to evaluate global purchasing power parity (PPP), currency valuations, data structures, and missing-data patterns across countries and over time.

Methodology
Loaded The Economist’s Big Mac Index dataset from GitHub, covering 57 countries and 45 periods from April 2000 to July 2026.
Examined the dataset using cross-sectional, time series, and panel data structures.
Computed purchasing power parity (PPP) exchange rates and currency valuation percentages relative to the U.S. dollar.
Evaluated missing-data patterns and classified Russia’s exit from the dataset as Missing Not At Random (MNAR).
Created a bar chart to compare currency valuations across countries and a time series visualization to analyze changes in valuations over time.
Key Findings

Switzerland was persistently overvalued relative to the U.S., with the Swiss franc 41.8% overvalued in the July 2024 cross-section. Japan showed the opposite pattern, with the yen undervalued on average in every decade represented in the dataset. Overall, the analysis demonstrates how the Big Mac Index can be used as a simple measure of purchasing power parity while also highlighting the importance of data structure and missing-data patterns when interpreting economic data.
